Saya memiliki ketertarikan yang besar pada dunia IT dan teknologi, khususnya pengembangan web, frontend, serta berbagai pekerjaan yang memanfaatkan komputer dan teknologi sebagai bagian utama dalam proses kerja. Saya senang bekerja menggunakan PC, mengeksplorasi software dan teknologi baru, mengolah informasi, serta mencari cara agar pekerjaan dapat dilakukan dengan lebih efektif dan efisien.

Dalam proses belajar dan bekerja, saya terbiasa memanfaatkan berbagai teknologi dan AI tools untuk membantu mempercepat pekerjaan, mengeksplorasi ide, meningkatkan kreativitas, serta menemukan solusi ketika menghadapi suatu masalah. Saya percaya bahwa teknologi bukan hanya tentang kemampuan menggunakan tools, tetapi juga tentang bagaimana memahami kebutuhan dan menemukan solusi yang tepat. Saya merupakan pribadi yang cepat belajar, adaptif, disiplin, dan memiliki rasa ingin tahu yang tinggi. Saat ini saya terus mengembangkan kemampuan dan terbuka terhadap berbagai kesempatan kerja yang memungkinkan saya belajar, berkembang, menggunakan kemampuan komputer dan teknologi, serta memberikan kontribusi terbaik bagi perusahaan.

05
Java Web Programming Data Visualization BPS Data Deployed

Indonesia Unemployment Dashboard

Dashboard ini merupakan project tugas mata kuliah Java Web Programming yang saya kembangkan untuk menyajikan informasi mengenai tingkat pengangguran di Indonesia dalam bentuk visual yang lebih mudah dipahami. Dalam proses pengerjaannya, saya diminta untuk menentukan ide website informasi sekaligus mencari sumber data resmi yang dapat digunakan secara legal.

Saya kemudian memilih Badan Pusat Statistik (BPS) Indonesia sebagai sumber data utama, khususnya data Tingkat Pengangguran Terbuka (TPT) menurut provinsi. Data tersebut saya olah dan sajikan dalam bentuk statistik, grafik, serta perbandingan data sehingga informasi mengenai kondisi ketenagakerjaan dapat dipahami dengan lebih cepat. Project ini menjadi pengalaman saya dalam mencari sumber data resmi, mengolah informasi, serta menyajikannya melalui dashboard web yang interaktif.
